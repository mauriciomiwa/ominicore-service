# Brainstorm — {{PROJETO}}

Caderno de ideias e teorias. **Não é regra, não é requisito, não é backlog e
não significa que algo será implantado.** Uma ideia pode ficar aqui para
sempre, e tudo bem.

Para a IA: o que está aqui é hipótese (`B-n`), nunca fato do projeto. Não
implemente, não abra change, não crie tarefa nem cobre nada a partir deste
arquivo sem pedido explícito do usuário. Pode registrar ideias quando ele
pedir e citá-las como "ideia em aberto".

- **Ideia:** uma frase sobre o que poderia ser diferente.
- **Teoria:** a ideia mais o porquê de funcionar e, se der, como saber se
  está errada (o dado ou experimento que a derrubaria).
- **Se um dia o usuário decidir levar adiante:** passa pela skill `sabatina`
  e só então vira RN, change, decisão ou item do `to-do.md`; a entrada vai
  para "Encerradas" com o destino.
- **Se for descartada:** também vai para "Encerradas", com o motivo — evita
  rediscutir do zero.

ID `B-n` global, nunca reaproveitado: próximo = maior existente + 1.
